牛油果站内在线游玩与生图

不想来回复制？在 牛油果 → 我的书架 → 在线游玩，选择已解锁且开放试用的作品。目前开放《长京十二年》，其他作品仍可按下面的教程复制或下载指令到聊天软件游玩。

  1. 配置对话 API：新增配置，填写名称、服务商的 HTTPS 基础地址与密钥，用途选“对话”。保留 /v1 或服务商要求的地址前缀。点击“拉取模型”，选择对话模型，再“保存并使用”。
  2. 开始对话：直接点“进入故事”，或发送第一句话。无需先填写身份，姓名、身份和路线可在对话中决定。画面里的行动按钮会直接调用自己的 API 推进剧情，也可自由输入行动。
  3. 保存与全屏：每部作品提供 3 个云存档，可以自定义名称、保存与导出 JSON。画面右上角支持全屏查看，全屏中仍可点选、停止生成和打开生图。
  4. 配置生图 API：点击“故事生图”，新增用途为“生图”的配置。同样要拉取模型、选模型并保存。对话与生图共用最多 5 个 API 配置位，旧配置默认是对话用途。
  5. 自动融入剧情 HTML：展开游玩页“剧情自动配图”，选择生图API并勾选允许调用。模型只为无人场景、器物、植物、光影与抽象意象编写装饰提示词，禁止人物、肖像、脸、人体、手、背影与人形剪影。插画通过渐隐底图、页角装饰或低对比雾化背景融入当前HTML，不单独插入图片卡片或图注。默认开局最多1张，之后每3个启用回合最多1张，每个存档系列最多10次，可调整间隔与上限。日常重复对话可以不配图。
  6. 生成与下载：描述人物、服饰、场景与画风，可点“加入当前剧情参考”，核对编辑后主动点击“生成一张”。每次只生成 1 张，可预览、下载 PNG/JPEG/WebP。

接口要求：对话使用 OpenAI 兼容 /models 与 /chat/completions；生图使用 /models 与 /images/generations。普通对话模型不一定支持生图，请先核对服务商说明和费用。图片最大 6 MB、边长不超过 4096 像素，支持静态 PNG/JPEG/WebP。

图片保存：此浏览器按当前账号保留最近 10 张本机记录，不随云存档同步；换设备或清理浏览器数据后无法找回，请及时下载。图片不会作为网站公开资源上传。

费用与密钥：调用费用由玩家自己的 API 账户承担。配置密钥在本站服务器加密保存，不返回明文，不进入对话存档和图片记录。对话会将文游指令与上下文发送给玩家选择的服务商；生图只发送确认后的提示词。

自动配图默认关闭，只有玩家开启后才按频率调用。文字会先显示并保存，配图失败仍可继续；失败、取消也计入上限，忙碌直接跳过，不自动补画或重试。刷新或换设备不会重新付费生图；本机图片仍在时会恢复到HTML。此联动仅适用于本站在线游玩，普通聊天软件的HTML预览不会自动调用API。取消、失败或超时后，服务商可能仍在处理和计费，请先核对服务商记录。关闭生图窗口继续等待，退出在线游玩则停止接收。

一轮是怎么走的

指令本身不需要安装。你只需要一个能聊天、并且能预览 HTML 的软件。

  1. 新建一个空对话。游戏过程中不要换对话，换了之后规则和前面的情节都会丢掉。
  2. 把某一份 .md 指令完整发出去。推荐直接发文件。复制粘贴也可以，但手机上很容易少掉后半段。
  3. 等回复完全停住。回复里应是一整页 HTML。
  4. 点击 HTML 预览，进入这一回合的页面。
  5. 点地点、人物、选项或翻页。这些按钮会把对应行动复制出来。
  6. 回到软件输入框，把刚复制的内容粘贴进去并发送。模型这时才结算，并给出下一页。

只打开预览、只翻着看，故事不会自己往下走。页面上如果写着「请粘贴到 DeepSeek 聊天输入框并发送」，手机上同样贴回你正在使用的 Chatbox 或 RikkaHub。

把指令发出去

优先发文件

  1. 找到要玩的那一份，文件名类似 温度借阅室_HTML恋爱文游指令.md。
  2. 用微信文件、网盘、数据线或隔空投送，把这个 md 传到正在聊天的那台设备。
  3. 在 DeepSeek 网页、Chatbox 或 RikkaHub 里点附件，选中这份文件。
  4. 输入框里补一句：请严格按照这份文件开始，只回复完整 HTML。
  5. 发送，然后等到回复停住。

也可以整段复制

  1. 用系统自带的文件或备忘录打开 md，从第一行全选，复制。
  2. 回到聊天输入框，用下面说的「长按粘贴」，不要走输入法剪贴板。
  3. 粘贴后滑到最底下，确认能看到「现在开始」以及后面的收束句，再发送。

Chatbox 遇到特别长的粘贴，有时会自动变成一个文件。这样可以直接发送。

手机粘贴容易缺后半段

不要用输入法里的剪贴板

搜狗、百度、讯飞等输入法面板上的「剪贴板」，经常只留下开头几千字。指令后半段的人物、按钮规则和「现在开始」会消失。模型只看到半份规则时，页面会缺按钮，或者根本不按 HTML 回复。

  1. 复制之后，点一下聊天输入框，让光标出现。
  2. 不要去点输入法候选栏、剪贴板小卡片或剪贴板历史。
  3. 在输入框的文字区域长按，等系统弹出「粘贴」。
  4. 点这个系统菜单里的「粘贴」。
  5. 滑到结尾核对。开头要有作品标题，结尾要有「现在开始」。少了任何一头，删掉重来，或改成发文件。

粘贴前可以在这里粗查一次

文字只留在这台设备的本页里，不会上传。查完可以清空。它只看字数、开头和有没有「现在开始」，不能代替你自己滑到文件最后一行。

生成完毕后再点预览

等回复停住

光标还在跳、代码还在变长时，不要打开预览。半截 HTML 会是空白页或坏掉的按钮。

按软件打开预览

Chatbox：点这条消息里 html 的 Artifact 或预览，需要时再全屏。RikkaHub：点代码块右上角的「预览」。电脑 DeepSeek：在网页里打开这段 HTML 的预览；如果它已经直接渲染成可点击页面，就在那个页面里操作。

点你要做的那一项

地点、人物、关系、消息、翻页、返回和自定义行动，点下去都会复制一条请求。自定义行动要先写字再点。空白不会提交。

贴回输入框再发送

看到「指令已复制」后，回到同一个对话的输入框，仍然用长按粘贴，然后发送。自动复制失败时，预览页下方会留着完整原文，长按那段文字复制，再贴回去。不要只凭「好像选中了」就认为已经复制成功。

玩的时候会遇到的情况

  • 预览是空白：多半是还没生成完，或这页 HTML 被截断。等停住后重开；仍然空白，就发送一句「上一次页面不完整，请只输出唯一完整的 html，不要在代码外面解释。」
  • 点了选项，故事没变化：复制只发生在你的手机上。没有把那句行动发送出去，模型不会结算。
  • 人物没有图片：指令里的图是电脑上的本地文件，聊天软件打不开。还没有公网图片地址时，页面用文字描写外貌，这是正常的。
  • 聊到后面开始忘事、页面变短：上下文满了。换一个上下文更长的模型，并继续留在这个对话里。电脑上直接用 DeepSeek 网页最稳。

免费生图 API 与额度怎么开通

官方资料核对于 2026-10-26。免费名单、实名要求和额度会调整，使用前以自己的控制台为准。

先试硅基流动 Kolors

官方价格页目前将 Kwai-Kolors/Kolors 标为免费；需完成实名认证，仍有每分钟和每日用量限制。官方限额规则。

  1. 打开 硅基流动控制台注册，按提示完成实名认证。
  2. 进入“API 密钥”，新建并保存密钥，不要公开或发给别人。
  3. 模型广场找到 Kwai-Kolors/Kolors，再次核对标价免费，查看 Rate Limits 中 IPM / IPD。具体限额以该模型、该账号当前显示为准，不能当作无限免费。
  4. 牛油果 → 在线游玩 → 剧情自动配图 → 新增 API，用途选“生图”；基础地址填 https://api.siliconflow.cn/v1，密钥填自己的 Key。
  5. 点击“拉取模型”，选择 Kwai-Kolors/Kolors 并保存。列表没有时检查实名、权限与公告，不要直接换成收费模型。
  6. 可先在“故事生图”手动试一张，成功后开启剧情配图，建议每3回合最多1张、上限5或10次。

怎么查看和等待额度恢复

模型详情的 IPM 是每分钟图片限制，IPD 是每日图片限制；账单/用量页可查看调用记录。遇到429先停止尝试，按服务商提示等待恢复，不擅自假定北京时间零点刷新。本站还有独立限制：每账号每10分钟最多6次生图请求、全站同时1路，通道忙或未到配图频率直接跳过，不自动补画。

免费模型和新手赠金不同：免费模型按当时标价费用为0；赠金有金额与有效期，用完可能收费。网页会员或聊天免费额度不等于生图API额度。不要把“每天若干次推理调用”误写成“每天同样张数的免费图片”。服务商自带AI生成标识保留，图片及时下载保存。官方生图接口说明。

其他来源：Hugging Face 免费账号每月有0.10美元推理额度，官方注明可能调整；其文生图接口不等于本站当前的Images格式，暂不作为直接接入方案。额度说明、接口说明。本站已按硅基流动公开格式做兼容，尚未用真实账号密钥实测。

免费 API 怎么领

电脑玩 DeepSeek 网页，不需要 API。手机上的 Chatbox 和 RikkaHub 要自己填接口。网页能免费聊天，不等于开放平台的 API 也免费，两套额度互不相通。

每个平台最后都要拿到三样东西：API Key、Base URL、模型 ID。Key 相当于密码，只填进自己的软件，不要发到群里，也不要截图外传。

下面的额度和模型名核对于 2026-10-19 的公开说明。平台会改活动和免费名单，以你打开控制台时看到的为准。

填进 Chatbox

检查失败时，把这两种拼法对调一次。智谱的主机例外，它的路径停在 /api/paas/v4，不要再额外拼一个 /v1。

哪种免费模型玩得动

每一回合都要写出一整页带样式和按钮的 HTML，还要记住开头那份很长的规则。参数很小的免费模型可以闲聊，却经常写到一半停住。

  • 先看上下文长度。指令本身就很长，窗口至少要有 64K，更长更好。
  • 在免费名单里挑更大的模型，避开同名的 Pro、付费标记和需要充值才解锁的型号。
